# Task 5 – Capstone Project & Incident Response

## 📌 About the Project
This project was completed as part of my Cyber Security & Ethical Hacking Internship at ApexPlanet Software Pvt. Ltd.

It focuses on Web Application Penetration Testing using **DVWA (Damn Vulnerable Web Application)** and simulating basic incident response procedures.

## 🛠️ Tools Used
- Kali Linux
- Burp Suite
- SQLMap
- Wireshark
- DVWA
- SecurityHeaders

## 🔍 Key Activities
- Reconnaissance and security scanning
- Vulnerability assessment and controlled penetration testing
- Identification of SQL Injection, XSS, CSRF, LFI and security misconfigurations
- Risk analysis and mitigation recommendations
- Incident detection, containment and response simulation
- Documentation with screenshots and findings

## 🎯 Learning Outcomes
Gained practical experience in web application security, ethical hacking, vulnerability assessment, risk analysis and incident response.
